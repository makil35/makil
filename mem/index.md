# Project Memory

## Core
- **Identity**: Ultra-luxury fashion. Fully bilingual (FR/EN). Contact: richard@makil-maqil.com.
- **Visuals**: Minimalist. Off-white bg, black text. Pure black (#000000) header & footer.
- **Logos**: Header logo is text-only link. Footer uses `logo-makil-monogram.jpg` (h-20, mix-blend-screen).
- **Pricing**: NEVER show prices. Use "Prix sur demande" or "Sur rendez-vous uniquement".
- **Terminology**: Use "Pièces Fondatrices" ("Founding Pieces") instead of "Collections".
- **Media**: Home hero must be a static portrait image for performance. NO looping video.
- **Forbidden**: Club and conciergerie features are permanently removed. Do not re-add.
